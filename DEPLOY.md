# Публикация на GitHub Pages

1. Открой `Settings` → `Pages` в репозитории.
2. В `Build and deployment` выбери `Deploy from a branch`.
3. Выбери ветку `main` и папку `/(root)`, затем сохрани.
4. После публикации сайт будет доступен по адресу вида `https://USERNAME.github.io/site/`.

`.nojekyll` добавлен специально для простого статического сайта без Jekyll.
