О визуалах

Откуда взяты картинки

Визуалы берутся из открытой библиотеки Workout Guide: 302 упражнения и 906 SVG-кадров. Код и документация доступны по MIT, а визуальные ассеты лицензированы по CC BY-SA 4.0. Для статических упражнений сайт показывает одну ключевую позу, для динамических — последовательность готовых кадров. Источник указан в каждом окне упражнения.
