# Гимнастика — статический сайт

Готовый одностраничный сайт-справочник по гимнастике с конструктором комплексов для дома, зала и уличной площадки.

## Файлы
- `index.html` — структура сайта
- `styles.css` — адаптивный дизайн
- `app.js` — база упражнений, фильтры и генератор комплекса

## Запуск локально
Можно открыть `index.html` двойным кликом. Для более корректной проверки через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Бесплатный хостинг
Сайт подходит для GitHub Pages, Cloudflare Pages, Netlify и Vercel как обычный статический проект.

## Что можно доработать
- добавить изображения/анимации техники упражнений;
- добавить поиск по упражнениям;
- сохранить выбранные комплексы в `localStorage`;
- сделать отдельную страницу каждого упражнения;
- добавить режим PWA для установки на телефон.
